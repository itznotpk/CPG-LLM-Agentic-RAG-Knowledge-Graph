## Appendix 4: WHO Classification and TNM Staging

### WHO Classification of Colorectal Carcinoma (2010)

| Tumour Type | Subtype |
|:---|:---|
| **Adenocarcinoma (NOS/usual-type)** | Well-differentiated, moderately differentiated, poorly differentiated |
| **Mucinous adenocarcinoma** | >50% mucinous component |
| **Signet-ring cell carcinoma** | Poor prognosis |
| **Medullary carcinoma** | Often associated with MSI-H |
| **Micropapillary carcinoma** | — |
| **Serrated adenocarcinoma** | — |
| **Cribriform comedo-type adenocarcinoma** | — |
| **Adenosquamous carcinoma** | — |
| **Spindle cell carcinoma** | — |
| **Squamous cell carcinoma** | — |
| **Undifferentiated carcinoma** | — |

> **Clinical Note:** Most CRC are adenocarcinoma. Signet-ring and mucin-producing subtypes have significantly poor prognosis.

---

### TNM Classification (7th Edition, 2009)

#### Primary Tumour (pT)

| Stage | Description |
|:---|:---|
| **pT1** | Tumour invades submucosa |
| **pT2** | Tumour invades muscularis propria |
| **pT3** | Tumour invades beyond muscularis propria |
| **pT4a** | Tumour penetrates visceral peritoneal surface |
| **pT4b** | Tumour directly invades or is adherent to other organs/structures |

#### Regional Lymph Nodes (pN)

| Stage | Description |
|:---|:---|
| **pN0** | No regional lymph node metastasis (minimum 12 nodes evaluated) |
| **pN1a** | 1 node involved |
| **pN1b** | 2–3 nodes involved |
| **pN1c** | Tumour deposits in subserosa/mesentery/pericolic/perirectal tissues without nodal metastasis |
| **pN2a** | 4–6 nodes involved |
| **pN2b** | 7+ nodes involved |

#### Distant Metastasis (pM)

| Stage | Description |
|:---|:---|
| **pM1a** | Single site metastasis |
| **pM1b** | Multiple sites or peritoneal surface metastasis |

> **Notes:**
> - pMX does not exist
> - pM0 does not exist (except at autopsy)
> - pM1: Distant metastasis proven microscopically (if biopsy of suspected site is negative → cM0, NOT pM0)

#### Modified Dukes Staging

| Stage | Description |
|:---|:---|
| **A** | Growth limited to wall/muscularis propria, nodes negative |
| **B** | Growth beyond muscularis propria, nodes negative |
| **C1** | Nodes positive, highest node negative |
| **C2** | Highest node positive |
| **D** | Histology-proven distant metastasis |

> **Local practice:** Pathology reports include both 5th and 7th editions of TNM staging, plus Dukes' staging.

## Appendix 5: Histopathology Reporting Proforma

### 1. Gross Description

| Item | Details to Record |
|:---|:---|
| **Specimen type** | Nature and type of operation |
| **Tumour site** | Location within colon/rectum |
| **Maximum tumour diameter** | In mm |
| **Distance to nearer longitudinal margin** | In mm |
| **Relation to peritoneal reflection** | For rectal tumours only |
| **Grade of surgical excision plane** | For TME/APR specimens |
| **Additional comments** | Any relevant macroscopic findings |

---

### 2. Microscopic Assessment

| Item | Options/Details |
|:---|:---|
| **Tumour type** | Adenocarcinoma (NOS); specify if other (e.g. mucinous) |
| **Differentiation** | Well / Moderately / Poorly differentiated |
| **Local invasion (pT)** | pT1 (submucosa) → pT4b (adjacent organs) |
| **Max extramural spread** | Distance beyond muscularis propria in mm |
| **Response to neoadjuvant therapy** | No viable tumour / scattered cells / residual cancer / extensive residual |

---

#### Additional Histological Features (Optional/Non-core)

| Feature | Options |
|:---|:---|
| **Lymphatic invasion** | Yes / No |
| **Perineural invasion** | Yes / No |
| **Leading edge of tumour** | Expansile / Infiltrative / Mixed |
| **Extracellular mucin (>10% but <50%)** | Yes / No (not applicable if mucinous carcinoma) |
| **Intratumoural lymphocytic infiltrate** | None / Mild (3–15 per HPF) / Marked (>15 per HPF) |
| **Peritumoural lymphoid aggregates** | None / Mild (occasional) / Marked (≥2 aggregates with germinal centres per section) |

---

#### Margin Assessment

| Margin | Assessment |
|:---|:---|
| **Proximal doughnut** | Yes / No / NA / Not submitted |
| **Distal doughnut** | Yes / No / NA / Not submitted |
| **Proximal longitudinal margin** | Involved (Yes) / Clear (distance in mm) |
| **Distal longitudinal margin** | Involved (Yes) / Clear (distance in mm) |
| **Circumferential margin** | Involved (Yes) / Clear (distance in mm) / NA |

> **Clinical Note:** Circumferential margin of ≤1 mm is considered involved.

---

#### Metastatic Spread Assessment

| Item | Details |
|:---|:---|
| **Total lymph nodes identified** | Number |
| **Involved lymph nodes** | Number (pN staging) |
| **Highest node involved** | Yes (Dukes C2) / No |
| **Tumour deposits** | Yes (number) / No |
| **Distant metastasis (biopsy-confirmed)** | pM1a (single site) / pM1b (multiple sites/peritoneal) / NA / No |

---

#### Venous Invasion

| Depth | Options |
|:---|:---|
| **None** | — |
| **Submucosal** | — |
| **Intramural** | — |
| **Extramural** | — |

---

#### Complete Resection Assessment

| Status | Description |
|:---|:---|
| **R0** | Complete resection (>1 mm at all margins) |
| **R1** | Microscopic margin involvement |
| **R2** | Macroscopic margin involvement |

---

#### MMR Immunohistochemistry (if applicable)

| Marker | Status Options |
|:---|:---|
| **MLH1** | Normal / Equivocal / Loss of protein expression |
| **MSH2** | Normal / Equivocal / Loss of protein expression |
| **MSH6** | Normal / Equivocal / Loss of protein expression |
| **PMS2** | Normal / Equivocal / Loss of protein expression |

---

### 3. Diagnostic Summary

Final report should include: tumour type, differentiation, staging (TNM 5th + 7th edition + Dukes'), margins, and venous invasion status.

### Abbreviations

* **APR** = Abdominoperineal resection
* **CRC** = Colorectal carcinoma
* **MMR** = Mismatch repair
* **TME** = Total mesorectal excision
* **TNM** = Tumour-Node-Metastasis
* **WHO** = World Health Organization
